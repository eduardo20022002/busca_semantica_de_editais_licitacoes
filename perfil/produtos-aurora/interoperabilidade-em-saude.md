# Interoperabilidade em Saúde

A Aurora desenvolve soluções de integração entre sistemas de saúde, permitindo a troca de dados clínicos entre diferentes plataformas e instituições através de padrões abertos.

## Aplicações típicas

- Integração de prontuário eletrônico entre hospitais via padrão HL7 e FHIR
- Integração de sistemas de saúde via APIs de troca de dados clínicos
- Orquestração e monitoramento de integrações entre sistemas de saúde
- Governança e padronização de dados clínicos entre plataformas distintas
- Conector de integração entre sistema de laboratório e prontuário eletrônico hospitalar
- Integração de processos laboratoriais automatizados a sistemas hospitalares
- Integração de sistema de saúde municipal ou estadual com a Rede Nacional de Dados em Saúde (RNDS)
- API de interoperabilidade para troca de resultados de exames entre laboratórios e hospitais
